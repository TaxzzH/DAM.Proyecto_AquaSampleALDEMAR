# AquaTraz (Proyecto AquaSample)

## Resumen del Proyecto
**AquaTraz** es una aplicación móvil diseñada para resolver la lentitud de los procesos de recolección 
de choritos y creaciones de muestras. 

El objetivo es mejorar la rapidez, organización y trazabilidad del proceso de registro de muestras 
de la empresa ALDEMAR SpA, reemplazando el flujo manual actual. 

Permite al operador registrar la información y adjuntar evidencia en terreno, 
mientras que supervisores y analistas pueden revisar, validar y consultar los registros en 
tiempo real según su rol.

## Commits 

Conventional Commits:

tipo(alcance): mensaje corto y claro

1. El Tipo (tipo):
   Indica qué clase de trabajo acaban de hacer.

- feat (Feature): Añadieron una nueva funcionalidad o característica.
- fix: Arreglaron un error o bug.
- chore: Tareas de mantenimiento (ej. actualizar dependencias, configurar el proyecto) que no cambian el código de la aplicación para el usuario.
- docs: Cambios exclusivos en la documentación (como actualizar el archivo README.md).
- refactor: Modificaron el código para mejorarlo internamente, pero sin añadir funcionalidades nuevas ni arreglar errores.

2. El Alcance (alcance):
   Indica qué microservicio o módulo exacto se acaba de modificar.

3. El Mensaje:
   Debe ser breve (idealmente de 50 caracteres o menos) y usar verbos en modo imperativo, como si le estuvieran dando una orden al código. Usen "agregar", "corregir", "eliminar", en lugar de "agregué", "corrigiendo" o "agregado".

### Paleta de Colores
La paleta utiliza tonos asociados al agua y al entorno acuícola, transmitiendo una identidad tecnológica, limpia y profesional.
* **Principal (`#0077B6`):** Botones principales, elementos destacados y acciones importantes.
* **Secundario (`#00B4D8`):** Iconos, elementos secundarios y estados informativos.
* **Adicional (`#48CAE4`):** Detalles visuales, indicadores y elementos de apoyo.
* **Fondo (`#F5F9FC`):** Fondo general de las pantallas.
* **Texto (`#1B1B1B`):** Textos principales y títulos.
