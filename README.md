# AquaTraz (Proyecto AquaSample)

## Resumen del Proyecto
**AquaTraz** es una aplicación móvil diseñada para resolver la lentitud de los procesos de recolección de choritos y creaciones de muestras. El objetivo es mejorar la rapidez, organización y trazabilidad del proceso de registro de muestras de la empresa ALDEMAR SpA, reemplazando el flujo manual actual. 

Permite al operador registrar la información y adjuntar evidencia en terreno, mientras que supervisores y analistas pueden revisar, validar y consultar los registros en tiempo real según su rol.

### Paleta de Colores
La paleta utiliza tonos asociados al agua y al entorno acuícola, transmitiendo una identidad tecnológica, limpia y profesional.
* **Principal (`#0077B6`):** Botones principales, elementos destacados y acciones importantes.
* **Secundario (`#00B4D8`):** Iconos, elementos secundarios y estados informativos.
* **Adicional (`#48CAE4`):** Detalles visuales, indicadores y elementos de apoyo.
* **Fondo (`#F5F9FC`):** Fondo general de las pantallas.
* **Texto (`#1B1B1B`):** Textos principales y títulos.
